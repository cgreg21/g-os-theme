# Icon coverage

## MIME types

The `G-OS/scalable/mimetypes/` and `G-OS-dark/scalable/mimetypes/` directories contain individually authored, committed SVG files. They are not generated at build or install time.

Coverage includes PDF and office documents, plain text and Markdown, images, audio, video, compressed archives, source code and scripts, executable and library files, fonts, disk images, Linux packages, CSV and SQLite databases, and a generic binary file.

Both variants share the same file silhouette and family identity. The dark variant adjusts paper, outline, badge, and label contrast for dark surfaces.

## Existing assets

Application and symbolic icon coverage is maintained separately by the existing theme workflow. MIME SVGs are preserved as static repository assets and copied by the existing installation step.
