# G-OS icon assets

The Freedesktop icon themes are stored in this directory.

- `G-OS/`: light theme assets.
- `G-OS-dark/`: dark theme assets.
- `scalable/mimetypes/`: individually authored MIME SVGs committed directly to Git in both variants.

MIME icons are static source assets. They are not generated by `scripts/generate-icons.py` or by an install-time generator. The existing application and symbolic icon workflow remains separate.
